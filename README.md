# Shiny Teeth

A compact phone app for learning and recording **My Shiny Teeth and Me**.

Open https://heatherli72.github.io/shiny-teeth/

- Learn a line: tap words for pronunciation, IPA and Chinese meanings; Read or Play the line.
- Record with Singer or Band. The previous line always uses the original singer as a timing cue, then switches to your chosen backing for the target line.
- Sing selected sections and save named takes.
- My Song shows saved lines, plays individual recordings, assembles a full song and downloads WAV audio.

Recordings remain in each browser on that device. They are not uploaded to GitHub. Recordings on localhost and this public URL are stored separately.

The accompaniment is locally separated from the supplied original using Demucs; residual vocals may remain. Song timing is machine-assisted. Nunito font files include their SIL Open Font License.

Static HTML/CSS/ES modules. No login or build step required. GitHub Pages serves the main branch root.
